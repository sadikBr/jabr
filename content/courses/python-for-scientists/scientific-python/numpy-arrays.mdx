<Step kind="see" title="A whole column at once">

You have a formula for the height of a ball, $h = 20t - 4.9t^2$, and you want
its height at a hundred different times. With a list you would write a loop.
With **NumPy**, the library nearly all scientific Python is built on, you
write the formula once and it applies to every value together.

Run this. (The first time, NumPy takes a few seconds to download.)

Look at the line that computes `h`. It is the formula, exactly as you would
write it for a single number, but `t` holds five times, and so `h` comes out
holding five heights.

<Callout kind="definition" title="Arrays">

A NumPy **array** is a row of numbers that you can do arithmetic on as a
whole. By convention the library is imported under the short name `np`:

```python
import numpy as np

a = np.array([1.0, 2.0, 3.0])   # from a list
a * 2                           # array([2., 4., 6.])
a + 10                          # array([11., 12., 13.])
a ** 2                          # array([1., 4., 9.])
a + a                           # array([2., 4., 6.])
```

Every operation is applied **element by element**. Two arrays of the same
length combine item with item.

</Callout>

Two functions make arrays of evenly spaced values, which is what you want for
a time axis or for the $x$ values of a graph:

```python
np.linspace(0, 1, 5)     # 5 values from 0 to 1 inclusive: 0, 0.25, 0.5, 0.75, 1
np.arange(0, 1, 0.25)    # steps of 0.25, stopping before 1: 0, 0.25, 0.5, 0.75
```

NumPy has its own versions of the mathematical functions, which also work on
whole arrays: `np.sqrt`, `np.sin`, `np.cos`, `np.exp`. And an array can
summarise itself:

```python
h.max()        # the largest value
h.mean()       # the average
h.sum()        # the total
np.argmax(h)   # the position of the largest value
np.diff(h)     # the change from each value to the next
```

<Callout kind="warning" title="A list is not an array">

`[1, 2, 3] * 2` is `[1, 2, 3, 1, 2, 3]`: for a plain list, `*` means
"repeat". `np.array([1, 2, 3]) * 2` is `[2, 4, 6]`. If arithmetic on your data
does something strange, check whether it is really an array.

</Callout>
